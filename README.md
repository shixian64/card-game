## 开发交接

交给其他模型或开发者继续开发，请先阅读 [详细开发规格与交接文档](docs/DEVELOPMENT_HANDOFF.md)，也可直接使用 [下一模型启动提示词](docs/NEXT_MODEL_PROMPT.md)。文档涵盖现有实现、玩法规则、接口、数据、部署、已知问题及后续验收任务。

## 快速启动

Node.js 24，在本目录执行：

```sh
npm ci
npm run dev:local
```

游戏：http://127.0.0.1:3000  
后台：http://127.0.0.1:3000/admin

账号菜单可切换本地 A / B / C，A 是管理员。仅供本机联调，生产模式不允许开发登录。

## 开发和检查

```sh

npm run build
npm start
```

正式启动前复制 `.env.example` 为 `.env` 并配置来源、OAuth 与管理员白名单。完整说明：[自托管](../docs/self-hosting.md)。

## 范围

人口从 3 升到 6，按人口上阵卡牌，在 4 × 7 部署区安排站位，双方进入 8 × 7 战场自动移动和释放技能；射程、护甲 / 魔抗及属性 / 职业羁绊参与计算，最多 32 回合。服务器预计算确定性结果，客户端只回放；完成后由服务器一次结算，不接受客户端自报胜负。当前是电脑 PvE，没有实时 PvP 或装备系统。

36 种星灵有独立技能配置，分为 5 种职业（坦克、战士、射手、法师、刺客），共享 6 幅原创插画。强化每升一阶仅增加 3% 生命 / 2% 攻击，主要提供视觉进阶。服务器保存账户资产；市场支持紧凑列表、筛选分页、真实成交行情与个人记录；挂单、赠送、好友和世界 / 私聊保持可用。交易只使用游戏内星币，没有真实充值或现金交易。聊天使用短轮询更新。

本轮代码只在本地；旧 Sites 站点未更新。ChatGPT OAuth 缺少真实 Client ID，尚未完成外部登录联调。Docker 仅提供部署配置，未替用户部署远程服务器。

## 10 分钟局内经济

- 固定 8 轮，每轮 40 秒经营、35 秒战斗；服务器时钟推进，离线不会暂停，刷新不重发奖励。
- 初始 12 局内金币、3 人口、最多 2 张临时副本；商店仅招募本局开始时拥有的卡牌定义。
- 5 格商店，R / SR / SSR 售价 1 / 2 / 3 金；刷新 2 金，可锁店。局内副本不消耗永久收藏。
- 每轮基础收入 5，结算前每 10 金产生 1 利息（上限 5）；胜利 +1，2 连胜或连败 +1、4 连起 +2。
- 4 金买 4 XP，每轮自然 +2 XP；人口从 3 到 6 的升级需求为 6 / 10 / 14 XP。
- 3 张同名同星合成更高星，最高 3 星；每升一星 +12% 生命 / +8% 攻击。永久等级每升一级 +3% 生命 / +2% 攻击是独立系统。
- 局内金币不兑换市场星币。8 轮结束按胜场奖励星币与星尘，退出不奖励。
- 收藏插画不叠稀有度 / 属性 / Lv 标签，信息集中到详情；合成分解仅显示已拥有卡牌。

经济借鉴利息、刷新与运营取舍，不复刻原作赛季规则；参考：[TFT 官方开发复盘](https://teamfighttactics.leagueoflegends.com/en-us/news/dev/dev-teamfight-tactics-dragonlands-learnings/)。
## 沉浸式界面

已登录且账户数据加载完成后，对战页使用全视口游戏布局。离开对战恢复原页面滚动与导航。返回大厅只改变页面、不退出或暂停对局；系统全屏依赖浏览器权限，失败时保留满视口界面。
