# 星序网页原型

React + TypeScript + Vite，纯规则模块与界面分离。此目录是当前可运行应用；不是早期工坊生产链实验。

## 运行

建议 Node.js 24.x。在本目录执行：

```powershell
npm install
npm run dev
```

默认打开 http://127.0.0.1:5173。开发服务仅监听本机；端口被占用时以 Vite 输出为准。

```powershell
npm test
npm run build
npm run preview
```

- `npm test`：使用 Node 内置测试运行器验证规则、资源变化、存档校验与重复结算保护。
- `npm run build`：先执行严格 TypeScript 检查，再将静态资源输出到 `dist/`。
- `npm run preview`：本地预览生产构建，默认端口 4173，不是生产服务器。

2026-10-11：192 项自动测试、TypeScript 检查和生产构建通过。浏览器验证仍在进行，不在此提前声称完成。

## 代码与素材

| 路径 | 用途 |
| --- | --- |
| `src/App.tsx` | 五页面、交互、弹窗和存档入口 |
| `src/engine.ts` | 纯函数规则、资产变更、培育流程、存档校验 |
| `src/data.ts` | 12 种卡牌、组合、天赋、环境和经济参数 |
| `src/style.css` | 响应式视觉、动画与减少动态效果支持 |
| `public/art/` | 6 幅原创生成卡面，部分定义共用美术 |
| `tests/` | 当前网页原型的自动测试 |

设计图与生成提示词保存在仓库上层的 `design/ui/`。界面使用真实组件实现，不以整张设计图替代可交互界面。

## 存档与限制

存档保存在当前浏览器、当前网站来源下的 localStorage（`asteria.save.v1`）。不同端口、浏览器或设备不共享进度；清理网站数据会删除存档。可从左下角探索者设置导出或导入 JSON，导入前会要求确认覆盖。

已实现同卡强化、分解和定向制作；特效兑换待定。没有真实多人交易、充值、云同步或在线排行榜。全部资源由本地客户端计算，**不是可靠的线上资产账本，也没有服务端反作弊能力**。
