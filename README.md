# 星序 · 双人短局自走棋与交易社区版

## 开发交接

交给其他模型或开发者继续开发，请先阅读 [详细开发规格与交接文档](docs/DEVELOPMENT_HANDOFF.md)，也可直接使用 [下一模型启动提示词](docs/NEXT_MODEL_PROMPT.md)。文档涵盖现有实现、玩法规则、接口、数据、部署、已知问题及后续验收任务。

本仓库根目录就是应用目录。`artifacts/` 包含关键验收截图与平衡记录；`design/` 和部分 `docs/` 保存历史设计，不代表当前玩法。

## 快速启动

Node.js 24，在本目录执行：

```sh
npm ci
npm run dev:local
```

游戏：http://127.0.0.1:3000  
后台：http://127.0.0.1:3000/admin

账号菜单可切换本地 A / B / C，A 是管理员。仅供本机联调，生产模式不允许开发登录。

## 开发和检查

```sh
npm test
npm run build
npm start
```

正式启动前复制 `.env.example` 为 `.env` 并配置来源、OAuth 与管理员白名单；双人短局相关开关（`LEGACY_MATCH_STARTS` 旧单人局新建、`DUEL_SCHEDULER_TICK_MS` 房间调度间隔）同样在 `.env.example` 中说明。完整说明：[自托管](docs/self-hosting.md)。

## 范围

主玩法是双人真实 1v1 短局：邀请码建房，同房间共享服务器权威时钟与结算。对战在 8 × 7 六边形战场自动移动和释放技能；射程、护甲 / 魔抗及属性 / 职业羁绊参与计算，服务器预计算确定性结果，客户端只回放，不接受客户端自报胜负。旧单人 PvE 局停止新建，仅作进行中存局收尾。

36 种星灵有独立技能配置，分为 5 种职业（坦克、战士、射手、法师、刺客），共享 6 幅原创插画。局外强化每升一阶仅增加 4% 生命 / 3% 攻击与技能，主要提供视觉进阶。服务器保存账户资产；市场支持紧凑列表、筛选分页、真实成交行情与个人记录；挂单、赠送、好友和世界 / 私聊保持可用。交易只使用游戏内星币，没有真实充值或现金交易。聊天使用短轮询更新。

代码在本地开发，GitHub 用于源码交接；旧 Sites 站点未更新。ChatGPT OAuth 缺少真实 Client ID；LINUX DO 登录已完成代码与模拟测试，Client Secret 未配置、未真实联调。Docker 仅提供部署配置，未替用户部署远程服务器。

## 对局玩法

双人短局（主玩法，`src/DuelArena.tsx`）：10 轮约 9 分 15 秒 = 3 轮野怪补给 + 7 轮双方交锋。开局从真实收藏锁 8 个卡种与本局品质（招募价 10–14 金），两个免费开局副本；人口按轮自动 3 → 6（星契「第六席」可到 7），不买经验。野怪轮发保底金币与临时装备三选一（默认两槽 / 单位，星契可扩展槽位；同组不重复、免费拆卸）；局内金币、星级与装备全部为临时资产。R2 / R5 / R8 各出现一次「星契」三选一（微光 / 星辉 / 星冕）：双方同候选、每档一张、已选对对手公开、到期自动选第一项；效果覆盖经济、商店、战斗、羁绊、装备与人口，只在本局生效。对局页同时显示按不同卡种计数的羁绊进度。终局按胜 / 负 / 平发 120 / 100 / 110 星币：同对手每日前 3 局全额、再 3 局半额，个人配额全模式共享（前 6 局全额、再 6 局半额，取二者较小系数）；对局未满 180 秒或投降 / 掉线判负方无奖励，且终局会展示实际到账与无奖励原因。

旧单人 PvE 局（`src/MatchArena.tsx`，停止新建）：固定 8 轮，每轮 40 秒经营 + 35 秒战斗。初始 120 局内金币；每轮基础收入 50，利息每存 100 金 +10（上限 50），胜利 +10，2 连胜 / 连败 +10、4 连起 +20。品质招募价 10 / 11 / 13 / 15 / 17 金，刷新 20 金，可锁店；3 张同名同星合成更高星（每星 +12% 生命 / +8% 攻击）。v3 终局只发星币（80 + 胜场 × 20，按每日配额 6 全额 + 6 半额）；星尘仅 v1/v2 存续局沿用旧公式。局内金币不兑换市场星币。

星契的规则、20 张效果表、实现边界与未验证项见 [星契设计](docs/AUGMENT_GAME_SYSTEM_DESIGN.md)。

经济借鉴利息、刷新与运营取舍，不复刻原作赛季规则；参考：[TFT 官方开发复盘](https://teamfighttactics.leagueoflegends.com/en-us/news/dev/dev-teamfight-tactics-dragonlands-learnings/)。
## 沉浸式界面

已登录且账户数据加载完成后，对战页使用全视口游戏布局。离开对战恢复原页面滚动与导航。返回大厅只改变页面、不退出或暂停对局；系统全屏依赖浏览器权限，失败时保留满视口界面。
