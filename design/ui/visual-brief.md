# 星序视觉与交互方案

日期：2026-10-11。首版为浏览器本地原型。

## 视觉主张
暖白图鉴纸面、深墨导航与克制的香槟金细节，以原创星灵卡面作为视觉中心。参考成熟游戏的导航、收藏网格与档案查看方式，不复用角色、商标或素材。

## 内容布局
左侧主导航；中部收藏与六卡培育阵容；右侧当前星灵档案。一级操作是开始培育，次级操作是强化、分解和定向制作。其他页面保持同一套导航与资源栏。

## 交互主张
卡牌依次入场；悬停微抬起、选择金边；手牌选择与顺序调整即时更新组合预览；召唤翻牌和结算递进揭示。支持减少动态效果。

## 玩法原型
六卡构筑，短程分回合培育，手牌选取和排序触发同相、三相、首尾呼应与卡牌特性。中途选择规则天赋，结束保存不同成果。同卡强化消耗重复实例，分解获得星尘，制作可选择目标卡。特效兑换不实现。

## 技术选择
React + TypeScript + Vite。纯函数规则层与 UI 分离，版本化 localStorage 存档，Node 内置测试覆盖规则、经济与防重复结算。首版不声称具有真实联机交易，不使用客户端存档作为未来正式资产账本。
