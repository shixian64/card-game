## 本轮已确认需求

### 1. 抽卡、交易与统一品质

永久卡主要通过抽取和玩家交易获得。每一种卡都具有相同、完整的品质阶梯；同一个 defId 可以有不同品质的实例，不再把某种卡固定为 R、另一种卡固定为 SSR 当作这一需求的实现。

抽卡可直接获得不同品质，品质越高，最终抽取概率越低。品质档数 / 名称及概率尚未指定，你需提出草案；同时说明旧包内保底和旧定义级稀有度如何处理，不能把基础权重与包内修正后的最终分布混淆。

### 2. 同卡概率合成

用相同卡种合成升级永久品质：通常升一级；有失败，品质越高失败概率越高；失败随机返还一定数量卡牌；极低概率一次连升两个品质。

先明确主卡与材料、材料品质 / 数量、费用、失败主卡处置、返还数量 / 品质分布、普通成功 / 失败 / 连升的互斥概率和近顶级封顶规则。**这些具体数值没有被用户预先指定，不能把自拟规则当成定案，尤其不能擅自销毁主卡或全部材料。**

永久品质与局内三合星独立；不要把局内合星改成随机失败。抽卡 / 合成随机结果必须服务端落库，重试同一 requestId 复用原结果，不重抽、不重扣，返卡与扣材料同一事务提交。

### 3. 品质战力与局内价格联动

品质升级实际增强局内属性和技能效果，但幅度克制，不能夸张碾压；同一卡品质越高，局内购买金币越高。价格增长要与实际强度相称，高品质不能性价比压倒一切，也不能贵到永远不值得买。

给出逐品质“属性 / 技能 / 购买价 / 出售价”表，用同预算、同敌阵、多职业 / 站位 / 局内星级对照验证，而不是只比较攻击力百分比。

特别处理现有 1 / 2 / 3 金整数步长、最高永久等级独占本局卡池、不同品质合星和出售的影响：不能小幅增强就价格翻倍，不能升级后被迫只能买昂贵卡，不能产生买卖 / 合星套利。若调整计价单位，必须整体同步经营经济并设计存量兼容，不能只改一个价签。

### 4. 场景化六边形对局棋盘

地图不要像表格。参考金铲铲类竞技场的空间组织，采用错列六边形逻辑：**全场 8 行×7 列，共 56 格；单方下半场 4 行×7 列，共 28 个部署位置**。28 是可选位置，不是自动增加人口。数值参考来源和证据边界已记在交接文档第 8.4.2 节，不宣称掌握金铲铲内部实现。

使用原创场景、地面透视、卡牌棋子；平时弱化网格，备战 / 选中 / 拖拽时显示淡六边形提示，不搬运原作素材、不做 3D 英雄。

不能只改 CSS 外形：六邻接、六边形距离、BFS、选敌、射程、范围技能、坦克吸引范围、刺客落点、推荐布阵和回放必须统一。坐标投影与鼠标 / 触屏命中一致；保留或显式迁移旧 slot / 对局 / 回放。实际查看桌面和小横屏效果。
