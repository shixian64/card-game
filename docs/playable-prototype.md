# 星序：当前可玩原型

更新：2026-10-11。状态：本地网页原型已实现，浏览器验证进行中。

## 目标与边界

验证“组合发现 + 培养成果”是否形成值得重复游玩的核心体验，不依赖战斗或长篇剧情。抽卡、同卡强化、分解和定向制作为该体验服务。旧工坊生产链已搁置，不继续作为主玩法。

首版没有真实多人交易、充值、云端资产或在线排行榜。自由交易属于后续服务端工作，当前不能在玩家之间真实转移卡牌。客户端 JSON 校验只是防止损坏数据破坏本地流程，不等于反作弊或可信资产验证。Pocket 式特效兑换待定，未实现。

## 已实现页面

| 页面 | 可做的操作 |
| --- | --- |
| 星灵图鉴 | 星相筛选、搜索、显示未收录、查看档案、编队与选择主灵、同卡强化、分解 |
| 共鸣培育 | 六卡阵容、选择与排序投影、即时计分预览、重新感应、天赋选择、结算 |
| 观星召唤 | 三张一组抽取、概率与保底说明、查看本次结果 |
| 兑换工坊 | 分解未强化重复卡、使用星尘定向制作目标卡 |
| 培育手记 | 查看成果、最高分、组合发现及历史详情 |

内容为 12 种独立卡牌定义、3 个星相、6 幅原创生成卡面。部分卡牌定义共用卡面，不能把它描述为 12 幅独立美术。

## 一次培育

1. 选择 6 种已拥有的星灵，第一张为主灵；培育开始后本次阵容锁定。
2. 全程 6 回合，每回合从 5 张投影中选择 1–3 张，基础行动力上限为 7。
3. 调整出牌顺序，利用同相共鸣、三相轮转、首尾呼应及卡牌特性；界面即时显示环境加成和分数。
4. 每回合可重新感应一次；第 2、4 回合结束后，从候选天赋中选择一个，改变后续规则。
5. 完成后获得星币和星尘，留下灵感、亲和、专注、评级和组合记录；保存主灵最高纪录，最多保留最近 50 次成果。

投影不是收藏卡的消耗品。成长数值属于本次培育结果记录，不应宣传为已经实现了永久属性继承。长期强化目前由同卡升阶提供。

未完成旅程可以离开页面后继续，刷新后恢复已保存阶段；天赋界面可选择稍后继续。结束未完成培育不会得到完成奖励，也不销毁收藏卡。

## 重复卡与获取

- **同卡强化：** 最高 3 阶，使用未强化同名重复卡与星币，每阶使主卡基础共鸣永久 +2。主卡及素材不能消耗正在培育中的实例。
- **分解：** 保留最后一张，已强化或培育中的实例不作为回收材料；其余可分解为星尘。
- **定向制作：** 消耗星尘确定获得目标卡，提供非随机的补卡路径。分解与制作存在资源损耗。
- **观星：** 每次获得 3 张，优先消耗观星券，否则消耗星币；基础概率和整组保底规则在界面中公开。没有真实支付。

以上数值是原型测试参数，尚未完成长期产销、留存与经济平衡验证。

## 技术与数据

React + TypeScript + Vite；规则实现位于 `web/src/engine.ts`，配置位于 `web/src/data.ts`，UI 位于 `web/src/App.tsx` 与 `web/src/style.css`。

localStorage 使用版本化 JSON 存档，支持导入、导出和重置。导入会校验结构、引用、资源和培育记录一致性。自动存档失败时界面提示导出备份；切换浏览器、来源或清除站点数据不会自动迁移存档。
